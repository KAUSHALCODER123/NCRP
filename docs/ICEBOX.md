# Icebox

Good ideas that are **not** being built before 28 Aug.

The purpose of this file is to make saying "no" cheap. An idea written down here is not lost — it is scheduled. Round 2 (7 Sept) exists precisely for these, with a week of mentorship in between.

**Rule: nothing moves from this file into the build before the Round 1 deadline.**

---

## Deferred to Round 2 (7 Sept)

| Idea | Why it's good | Why it waits |
|---|---|---|
| Assisted / Guardian mode | File on behalf of a parent; 71% of elders use basic phones and only 13% are online — this is the real victim population | Needs a second account model; Tier 1 must be flawless first |
| WhatsApp bot flow | Meets people where they already are | Can only be mocked in a browser; low demo return per hour |
| IVR / 1930 simulation | Shows the voice channel is designed, not ignored | Same — hard to demo in a browser |
| Public transparency dashboard (₹ reported / held / **returned** by state) | The accountability lever that makes every other fix stick | One screen, high polish cost, doesn't appear in the 2-min video |
| Suspect Registry appeal flow | Mandatory if we ever ship the lookup for real — unverified crowdsourcing wrongly flags legitimate businesses | Scam Check itself is Tier 2; the appeal is its dependent |
| Officer-side console | Judges explicitly do **not** evaluate the admin side | Rules say don't. One architecture-slide screenshot is enough |
| Full 22-language Bhashini integration | The production answer for a country that doesn't report in English | EN + HI proves the idea at 5% of the effort |
| Real bank API adapters | The actual product | Rules require a mocked backend |
| Offline-first PWA with queued submissions | Genuinely important in rural India | Service-worker complexity is a day we don't have |
| Chain-of-custody evidence hashing | Makes evidence court-admissible | Invisible in a demo; belongs in the architecture narration |
| ZK-proof suspect lookups | Answers "is this flagged?" without exposing complainants | Research-grade; describe it, don't build it |

## Explicitly rejected (not just deferred)

| Idea | Why not, ever |
|---|---|
| 3D / WebGL hero | The rules video warns directly against bells and whistles that don't serve the end consumer |
| Dark mode | A day of work, zero scoring impact |
| Native mobile app | Rules: *"If it doesn't open on a browser, it doesn't exist."* |
| Real authentication | Mocked accounts are required |
| Gamification / points / badges | Wrong emotional register for someone who just lost ₹47,500 |
| Landing page with marketing copy | Judges grade the citizen experience, not the pitch page |
